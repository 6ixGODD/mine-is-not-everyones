# ADR-0003: Write the Design Knowledge Base in English

## Status

Accepted.

## Decision

All `docs/` content is written in English. The repository root provides an English README and a Chinese translation.

## Rationale

English aligns with code, protocols, upstream documentation, and the user's learning goal. One language inside the design tree avoids duplicate documents drifting apart.

## Consequences

- user-facing Chinese explanations belong in `README.zh-CN.md` or external communication;
- identifiers and technical contracts remain English;
- Skills may converse in the user's language while writing repository docs in English.
